Входные файлы для просмотра пересечений:

```bash
nix develop
cmake --preset app -DVISUALIZER_SOURCE_DIR="$PWD/../3D-Visualizer"
cmake --build --preset app
nixGLIntel ./build/app/triangles inputs/input_100.txt
```

Красные треугольники пересекаются, серые — нет. Окно открывается всегда.
ЛКМ + движение мыши — вращение, ПКМ — перемещение, колесо — масштаб.
Камера изначально настроена на координаты в диапазоне [-10, 10].

Генерация произвольного числа треугольников:
```bash
python3 inputs/generate_input.py 250 inputs/mixed_250.txt --min -50 --max 50
python3 inputs/generate_input.py 100 inputs/repeatable.txt --seed 42
```

Диапазон координат задаётся через `--min` и `--max` (по умолчанию [-10, 10]). `--seed` позволяет повторить генерацию.

По умолчанию режим `mixed` создаёт 50% пересекающихся треугольников и 50%
непересекающихся. Пространство разбивается на ячейки с изолированными парами:
активная пара частично перекрывается, неактивная разделена. Плоскость каждой
пары выбирается среди XY, XZ и YZ. Между разными ячейками пересечений нет.
Доля относится к числу треугольников, участвующих хотя бы в одном пересечении,
и округляется до ближайшего допустимого чётного количества.

```bash
python3 inputs/generate_input.py 1000000 inputs/input_1000000.txt \
  --intersecting-fraction 0.5 --seed 42
```

Для 20% пересекающихся треугольников укажи `--intersecting-fraction 0.2`,
для полностью непересекающегося набора — `0`.
Старый режим независимых случайных вершин доступен через `--mode random`;
доля пересечений в нём не контролируется.
